## Legend

| Field        | Meaning                                                                                        |
| :----------- | :--------------------------------------------------------------------------------------------- |
| ID           | Internal agent identifier used in the graph and logs.                                          |
| Label        | Human-readable name of the agent.                                                              |
| Class        | Type of agent (role_agent, institution_agent, community_agent, etc.).                          |
| Tier         | Activation tier: **P** = Primary speaking agent; **R** = Rotating agent; **C** = Context only. |
| Evidence     | Source class of the agent's existence or role. See evidence key below.                         |
| Primary link | Parent hub or node this agent links to in the graph.                                           |

### Evidence key

- **D**: Documented in an official source or official dataset
- **O**: Real official institution or legal mechanism (simulated behavior is a model construct)
- **J**: Reported by journalism; requires source attribution
- **A**: Explicit simulation assumption or synthetic role identity
- **S**: Conditional scenario or shock, not a prediction
- **M**: Metric generated by the simulation
